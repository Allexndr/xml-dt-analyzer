# Анализ XML-деклараций на товары (прототип)

Веб-сервис: загрузка XML-декларации (ЕЭК R.055 v1.2.0), просмотр с номерами строк, вопросы на русском языке с ответами и ссылками на строки, автоматическая проверка по правилам Решений ЕЭК № 75, КТС № 257 и № 378.

## Устройство репозитория

| Путь | Что внутри |
|---|---|
| `backend/src/xmldt/indexer/` | Потоковый индекс XML: строки, смещения, пути (expat, без DTD) |
| `backend/src/xmldt/schema/` | Определение версии (в т. ч. в обёртке Keden) и проверка по XSD |
| `backend/src/xmldt/kb/` | Сборка базы знаний из Решений № 75, 90, 257, 378, 145 |
| `backend/src/xmldt/facts/` | Извлечение фактов из декларации по каталогу понятий |
| `backend/src/xmldt/rules/` | Компилятор и движок правил (таблица 3, условные и экспертные правила) |
| `backend/src/xmldt/ai/` | ИИ-слой: роутер, вызовы инструментов, проверка ответа, провайдеры, релей локальной модели |
| `backend/src/xmldt/api/` | FastAPI: файлы, вопросы, проверки, вход по e-mail, экспертная проверка, БД (SQLite/Postgres) |
| `backend/tests/` | Тесты (pytest) |
| `backend/tools/` | Синтетический пример, оценка ИИ, имитация локальной модели |
| `frontend/` | Интерфейс (React + TypeScript + CodeMirror 6) |
| `api/index.py`, `vercel.json`, `requirements.txt` | Развёртывание на Vercel (Python-функция + статический фронтенд) |
| `docker-compose.yml`, `deploy/` | Развёртывание в Docker (nginx + API), инструкция в `deploy/README.md` |
| `data/schemas/` | Официальные XSD R.055 v1.1.0 и v1.2.0 (альбом форматов ФТС) |
| `data/norms/` | Консолидированные тексты Решений и даты изменяющих актов |
| `data/kb/` | Каталог понятий, привязка к классификаторам, экспертные правила (YAML, правится руками) |
| `data/derived/` | Собранные артефакты базы знаний (генерируются `xmldt.kb.build`) |
| `data/ref/` | Справочник ТН ВЭД |
| `data/samples/` | Синтетическая ДТ для тестов (не реальная декларация) |
| `docs/` | План (`plan.md`), отчёт (`phase0-report.md`), контракт API (`api.md`), запрос заказчику |

## Секреты

В репозитории нет ключей, паролей и токенов. Все настройки задаются переменными окружения, шаблон в `.env.example`
(для локального бэкенда также `backend/.env.example`). Файлы `.env.local`, `.vercel/`, базы SQLite и загруженные
XML исключены через `.gitignore`. На продакшене ключи хранятся в переменных окружения Vercel.

## Запуск

Нужны Python 3.12 с [uv](https://docs.astral.sh/uv/) и Node.js 20+.

```bash
cd backend
cp .env.example .env.local      # впишите ключ OpenAI, если нужен ИИ; без ключа работает режим «без ИИ»
uv sync
set -a; . ./.env.local; set +a
XMLDT_DATA=../data uv run uvicorn xmldt.api.app:app --port 8000
```

Во втором терминале:

```bash
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173.

Проверки и пересборка базы знаний:

```bash
cd backend
uv run pytest -q
uv run python -m xmldt.kb.build --data ../data
```

## Что требует людей и данных заказчика

- **Подтверждение экспертом.** Всё, что подготовил ИИ-эксперт (правила, связи граф с элементами, привязки классификаторов, 177 редакций без даты), собрано на странице «Экспертная проверка» (`/review`). Эксперты задаются в `XMLDT_REVIEWERS`, входят по e-mail и подтверждают или отклоняют каждую позицию.
- **67 правил таблицы 3** требуют смысловой проверки (например, «наименование включает организационно-правовую форму при её наличии») — они тоже выведены на проверку эксперту.
- **ТН ВЭД** загружен из сторонней выгрузки (tws.by, 13 294 кода): перед продуктивным использованием заменить официальной редакцией ЕТТ ЕАЭС (`data/ref/`, пересборка `xmldt.kb.build`).
- **Даты 50 изменяющих актов** не получены: сайт-источник включил капчу. Повторный запуск `xmldt.kb.acts.fetch_dates` позже докачает их.
- **Реальные XML заказчика**: всё проверено на синтетической ДТ.
- **Docker-образы** описаны и проверены `docker-compose config`, но не собирались (демон не запущен на машине разработки).

## Продакшен

Развёрнут на Vercel: https://xml-dt-analyzer.vercel.app, база Neon Postgres (`DATABASE_URL`). Повторный деплой —
`vercel deploy --prod` из корня, подробности в `deploy/README.md`. Ограничения Vercel: загрузка до 4 МБ, нет
WebSocket (локальный ИИ через браузер отключён), вход по e-mail требует переменных `XMLDT_SMTP_*`.
